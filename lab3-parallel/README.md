# Лабораторная работа 3 — вариант 4

Вычисление SHA-256 для дерева файлов и поиск дубликатов. Генератор создаёт 48 файлов по 256 КиБ, из них восемь повторяют другие файлы. Последовательная, потоковая и многопроцессная версии сверяют все результаты. Замеры сохраняются по три прогона с медианой.

```bash
python hashing.py
python common_experiments.py
python -m unittest -v test_common
```

Для RabbitMQ (запускать отдельно, если есть ресурсы):

```bash
pip install pika
docker compose up -d
python rabbit_worker.py
python rabbit_producer.py part_0/file_00.bin
docker compose down
```

Воркер подтверждает сообщение только после записи результата, а повторная доставка с тем же `job_id` возвращает существующий результат. Каталог с файлами должен быть доступен воркеру.
