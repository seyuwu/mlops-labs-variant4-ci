# Лабораторная работа 5 — риск отчисления

Вариант 4. Синтетический набор данных описывает активность обучающихся; случайный лес оценивает вероятность отчисления. Это учебная модель, её нельзя использовать для автоматического решения о судьбе студента.

```bash
pip install -r requirements.txt
python src/generate_data.py --out data/raw.csv
python src/generate_data.py --out data/shifted.csv --rows 1200 --seed 99 --shift
dvc repro
python -m pytest -q
mlflow ui --backend-store-uri sqlite:///mlruns.db
uvicorn service.app:app --port 8000
```

Порог F1 = 0,70 задаётся до оценки. Конфигурация выбирается по отложенной валидации, итоговая метрика вычисляется на отдельном тестовом наборе. Файл `metrics_shifted.json` содержит результат стресс-теста с изменением распределения признаков и намеренным изменением зависимости целевой переменной. Для демонстрации блокировки: установить `METRICS_FILE=metrics_shifted.json` и запустить `pytest tests/test_quality.py::test_quality_gate` — тест должен завершиться с ошибкой.

MLflow хранит пять запусков локально в `mlruns.db`. Значения важности признаков показывают вклад в решения модели на этих данных, но не доказывают причинно-следственных связей. Модель включена в образ: это упрощает версионирование и откат, но для обновления требуется пересборка образа.

Необязательный LLM-контур описан в `docker-compose.llm.yml`: запрос `/explanations` ставит задачу в RabbitMQ и возвращает 202, а `/explanations/{id}` показывает результат из Redis. Воркер обращается к Ollama и сохраняет время до первого токена и скорость генерации. Контур не следует запускать на слабой машине одновременно с кластером: он требует отдельной загрузки модели `qwen2.5:0.5b` и дополнительной памяти.
